# To-Do List iOS Application  

A simple and efficient To-Do List app built for iOS, designed to help users manage their tasks effortlessly.  

## Features  
- User Authentication: Secure login and registration powered by Google Firebase.  
- Cloud Storage: User data and to-do list items are stored in Firebase for seamless access across devices.  
- Modern UI: Clean and intuitive interface designed with SwiftUI.  
- MVVM Architecture: Ensures better code organization and maintainability by separating logic from UI components.  
- Version Control: Git was used for version tracking, ensuring smooth collaboration and continuous improvements.  

## Technologies Used  
- Swift  
- SwiftUI  
- MVVM Architecture  
- Google Firebase (Authentication & Firestore Database)  
- Git for Version Control
